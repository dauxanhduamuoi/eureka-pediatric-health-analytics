# Artefact lịch sử khác

`pytest_cache_root_v2/` giữ cache pytest tự sinh từ root, đã xác minh định dạng và hash; không xóa vĩnh viễn. PDF, database kiểm thử và các payload cần xem xét vẫn ở vị trí được báo cáo. Cache có thể được pytest tạo lại khi người dùng chạy tests sau này.
